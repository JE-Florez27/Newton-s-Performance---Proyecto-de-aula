2. Modelo matemático

R(n) = a + b·n + c·n² / (K − n)

La función que buscamos igualar a cero es:

f(n) = R(n) − Rmáx

Derivada utilizada:

f′(n) = b + c(2nK − n²) / (K − n)²

Newton-Raphson actualiza la aproximación usando n siguiente = n actual − f(n) / f′(n).

Importante: los parámetros iniciales son hipotéticos. Para estimar un sistema real, deben ajustarse con mediciones obtenidas mediante pruebas de carga autorizadas.
